Workflow Deep Dive — Closed Deal Automation (Scenario 01)
01
Trigger Fires
GONG → WEBHOOK
Gong detects deal stage change to "Closed Won." Fires a webhook to Make.com instantly with call metadata and transcript URL.
deal_id: "APX-2891"
company: "Westfield Logistics"
value: 48000
owner: "sarah.kim@apex.com"
// + timestamp, call_id, transcript_url
02
AI Summarizes Call
MAKE → CLAUDE API
Make.com fetches transcript and sends it to Claude API via HTTP module. Claude returns a structured JSON summary — commitments, risks, next steps. No human reads the transcript first.
// prompt sent to Claude:
"Summarize this sales call. Extract: deal
summary, commitments made, next steps,
risk flags. Return valid JSON only."
// response: structured JSON · ~3 sec latency
03
Salesforce Updated
MAKE → SALESFORCE API
Make.com writes AI summary directly into the Salesforce opportunity record — custom fields for deal summary, commitments, and close date. Sales team opens Salesforce and it's already done.
endpoint: PATCH /services/data/v59.0/sobjects/Opportunity/{id}
AI_Summary__c: [claude_output.summary]
Commitments__c: [claude_output.commitments]
StageName: "Closed Won"
04
Slack + Notion Fire
MAKE → SLACK + NOTION APIs
Simultaneously: formatted Slack message to #wins with deal summary and rep tag. New Notion client page auto-created with onboarding checklist pre-populated from Claude output.
// Slack message — #wins channel:
🏆 Westfield Logistics — $48K Closed
Owner: @sarah.kim · Next: [next_steps]
// Notion page: /Clients/Active/Westfield
// Onboarding checklist auto-populated
