The Locker

Everything you have ever bookmarked on Instagram, TikTok and YouTube, stowed in one ledger.

Runs in your browser

Step 1 — Request the export

Open Instagram export →

accountscenter.instagram.com/info_and_permissions/dyi

  1. Sign in if prompted, then choose Download or transfer information
  2. Choose Download to device, date range All time, and set format to JSON
  3. Drop the downloaded zip file below.

Step 2 — Drop the file

Drop the export here The whole .zip file from Instagram, TikTok, or YouTube.
